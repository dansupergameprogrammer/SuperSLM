# SuperSLM 1.5.0

SuperSLM 1.5.0 establishes the QKC1 source-to-derived contract for QK-norm artifacts,
adds the A/B/C fused-K conversion flow with fail-closed publication, exposes channel-scale
headroom, and repairs residual addition on CPU and D3D12 GPU paths.

## What changed

QK-norm artifacts carry the `QKC1` channel table and its header flag. The loader validates
the serialized source scales and their derived landing, ratio, and carried-scale values before
forward execution. Conversion uses factored float calibration followed by capture passes A, B,
and C: it builds `max(float, A)`, then `max(float, A, B)`, and publishes the requested artifact
only after pass C converges. A failed pass C leaves no final-looking output artifact.

`--channel-scale-headroom` controls the fused-K channel-scale margin and defaults to 1.0. For
Qwen3-Embedding-0.6B, run the conversion with `--channel-scale-headroom 1.25`. The default
headroom's pass C clipped 7,713 of 282,103,808 callbacks (27.341 per million) and raised
`ChannelScaleDidNotConverge`; headroom 1.25 completed with 7 clipped callbacks
(0.024813560829352578 per million). The measured Qwen3 flow took 5,226 s end to end, with each
compiled capture pass taking about 1,495 s.

Residual adds now construct a complete row on the finer carried-scale grid and requantize it
once. If that candidate cannot be built or preflighted, the complete row is rebuilt on the coarser
grid. CPU and both GPU residual shaders use the same selected-grid construction.

## Compatibility and required action

QK artifacts must be reconverted from their source checkpoints for 1.5.0. Forward outputs change
for every model and are not bit-identical to 1.4.0. The artifact format is unchanged for non-QK
models. A residual operand with a zero carried-scale mantissa surfaces as
`SSLM_ARTIFACT_REJECTED`.

inputs, or corpora.

On corpus-239, the Qwen3 retrieval difference is not resolved: the discordant queries split

with the float anchor independently required to be 146 or 147 correct queries.
