# SuperSLM 1.4.0

SuperSLM 1.4.0 adds end-to-end Qwen3/QK-norm support. The reference pipeline now
recognizes Qwen3 checkpoint namespaces and Q/K norm gains, calibrates the finalized
carried-scale contract, and emits artifacts that run through both the CPU engine and
the D3D12 GPU path.

## Compatibility and required action

Released 1.3.1 artifacts remain compatible. QK-norm artifacts produced by development
builds before the final 1.4 contract are deliberately incompatible: reconvert them from
the source checkpoint. Their K post-norm landing reciprocal and carried-scale data do not
encode the contract the final runtime validates and executes.

GPU dispatch budgets remain model-aware. Legacy models use 24 dispatches per transformer
layer, exactly as in 1.3.1. Models carrying QK norm use 25. A budget below the relevant
per-layer count cannot advance a layer; multiples retain whole-layer slicing semantics.

## C++ API migration

The D3D12 GPU status type is now a scoped enum so the GPU and CPU public headers can be
included together safely. Change unqualified GPU constants such as `SSLM_OK` and
`SSLM_BUSY` to `SslmGpuStatus::SSLM_OK` and `SslmGpuStatus::SSLM_BUSY`. The CPU `extern
"C"` ABI and its `sslm_status` constants are unchanged.

Every public GPU function that returns `SslmGpuStatus` is now `noexcept`. Allocation
failures return `SslmGpuStatus::SSLM_GPU_ALLOCATION_FAILED`; other unexpected C++
exceptions are contained and mapped to the existing device-loss status.

## CMake consumers

The installed `superslm::superslm` target now propagates its C++20 requirement, so
consumers do not need to set a project-wide language standard. A Windows CPU-only build
does not require DXC when configured with `-DBUILD_TESTING=OFF` and the default
`SUPERSLM_BUILD_GPU=OFF`; the ordinary default build succeeds and creates no test target.

GPU packages install their compiled shaders and export a supported deployment helper:

```cmake
find_package(superslm REQUIRED)
target_link_libraries(my_app PRIVATE superslm::superslm_gpu)
superslm_deploy_gpu_shaders(my_app)
```

The helper copies the installed shader set beside the executable in the runtime layout
expected by SuperSLM.

## Additional hardening

Sequence reset now clears the aggregate and every per-site saturation counter on both
CPU and GPU. The reference pipeline's safetensors reader rejects malformed lengths,
out-of-bounds, overlapping, or incompletely indexed ranges; dtype/shape byte-count
mismatches; headers over 100 MB; duplicate JSON keys; and non-string metadata values.
The FP-free determinism gate now uses bounded production hash-table witnesses instead of
depending on enormous standard-library reservations and process timeouts.
